# Password Generator

A secure random password generator built with python.

## Description

This program generates random passwords with a minimum length of 12 characters.
Each password includes at least one letter, one digit, and one special character.

## Features

1. Generate random passwords
2. Set the password length(minimum 12 characters)
3. Include uppercase and lowercase letters
4. Include numbers and special characters
5. Randomize the order of characters
6. Handle invalid suer input

## Technologies

Python 3
Secrets modules
String modules

## Python Concepts Used

- Variables
- Strings and lists
- Loops (while and for)
- Conditional Statements (if / else)
- Exception handling (try / except )
- Functions (len, list, join)
- Modules and imports
- Random selection and shuffling

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command: python main.py
